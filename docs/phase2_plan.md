# QQ 正文与学业清单实现计划

用户已明确要求直接实现；在当前 D 盘项目保留所有已有功能，使用测试驱动流程，不再停在方案审批。

基线：Git 工作区干净，56 项 pytest 通过。

- [x] MIME BODYSTRUCTURE 解析与文本 part 选择，只 PEEK 文本正文，跳过附件、嵌套邮件，限制读取大小，保留只读连接与原有邮件头命令。
- [x] MailDocument/StudyItem 模型，规则提取多个学业事项，明确日期才识别；模糊日期、无时区日期和不完整正文标为待核对。
- [x] SQLite 文档与事项存储：来源键含账号标识、UIDVALIDITY 和 UID；导入与提取同一事务；重复更新不重复插入，保留用户完成状态。
- [x] CLI sync、todos、complete、import-canvas、digest；默认 Mock、真实 QQ 需显式授权；Canvas 只允许用户提供的本地 TXT/Markdown 文件，没有外部 API。
- [x] 完整离线 pytest、Mock 流程验证、已授权真实 QQ 小范围只读验证、独立代码审查、文档。
- [ ] GitHub 同步并确认 CI。

隐私：正文与数据库只存本机 data/，不保存原始附件或凭证，不上传外部模型。不会发送或修改任何邮件。清单是本地展示，不进行 SMTP 或其他消息发送。

同步范围：本版可配置最近 1–100 封邮件，保留来源覆盖范围；尚不承诺全部历史/完整增量同步。Canvas 文本导入保留人工来源和导入时间，不能代表已自动检查 Canvas。
