# Study Info Assistant：目标与进度

用户目标：只读查看 QQ 邮箱与获准来源，每半天整理学业待办。开发持续同步 https://github.com/baihaoyang11/study-info-assistant。

## 已实现（2026-10-12）

- 原有 QQ 邮件头、CLI、Mock 与 56 项测试保留。
- QQ 文本正文只读采集，跳过附件与嵌套邮件；最近 1–100 封窗口可配置。
- SQLite 保存正文、来源证据、完成状态与采集结果，重复来源更新、事务写入。
- 本地规则提取作业、考试、截止事项与行动通知；模糊时间和不完整来源需人工核对。
- sync、todos、digest、complete、import-canvas CLI。
- Canvas 仅手动导入 UTF-8 TXT/Markdown，不绕过学校限制。
- 96 项离线测试通过；3 封真实 QQ 正文只读小范围验证成功。

## 尚未完成

- 完整增量游标、超出最近窗口的漏信恢复与全历史覆盖。
- 丰富日期语法、跨来源事项合并和手动纠错界面。
- 将既有半日任务接入正文/本机数据库，并验证实际定时运行。当前桌面任务仍为 09:00、21:00 Asia/Shanghai 最近 10 封邮件头试运行，本次未升级。
- 常驻主机、关机时运行和独立摘要送达渠道；没有发送邮件模块。
- Canvas 外部读取须先取得学校允许的接入方式，再独立实现与验收。

## 运行边界

本机 CLI 可以随时手动采集和查看清单；数据库与摘要属于私有明文资料，不进入 Git。来源失败明确显示，空清单不代表没有任务。Mock 与真实来源建议使用不同数据库。

桌面任务依赖本机开机、应用运行、项目目录和网络权限；没有保障持续运行的服务器。用户已授权 QQ 只读访问，但禁止发送或修改邮件；新增送达渠道须另行明确范围。
